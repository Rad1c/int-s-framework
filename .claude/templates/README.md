# Templates

This folder contains reusable starting points for artifacts that are created repeatedly across projects.

A template should:

- be project- and technology-neutral unless its name says otherwise;
- contain structure and guidance, not invented project data;
- use clear placeholders for required input;
- stay small enough to adapt without deleting most of it.

Do not add a template for a one-off artifact. Run `sync-registry` after adding or removing one.
