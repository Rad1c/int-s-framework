# Implement Feature

Use this playbook to deliver a feature from requirement to verified change.

1. Confirm the goal, scope, constraints, and acceptance criteria.
2. Inspect the existing flow, conventions, and reusable code.
3. Choose the smallest change that satisfies the requirements.
4. Implement the change within the owning component.
5. Add or update the smallest relevant verification.
6. Run affected checks and review the final diff.
7. Update documentation when behavior or operation changed.

Done means the acceptance criteria are met, relevant checks pass, and known limitations are explicit.
